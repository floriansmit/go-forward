# Temporarily bundled DFM Generator

`DFMGenerator_GRDECL.exe` is a separately developed executable by Michael J. Welch and contributors. It is licensed under the Apache License 2.0 and is temporarily included with GO-Forward so users can run the dashboard demonstrator before the official upstream release is published.

It is not GO-Forward dashboard code. GO-Forward invokes it as a separate process and users can select another executable in **FFM Run DFM**.

The official future distribution will be available from [JointFlow/DFMGenerator](https://github.com/JointFlow/DFMGenerator). See the root [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) for attribution and the SHA-256 of this bundled binary.
